# Nicolas Personal Calendar — sitio informacional

Sitio público de documentación de la aplicación personal «Nicolas Personal
Calendar»: un lector de **solo lectura** del propio calendario de Google
Calendar (API oficial v3, OAuth 2.0, únicamente los scopes de lectura de
calendarios y eventos).

Contenido:

- `index.html` — presentación y propósito de la aplicación.
- `privacy.html` — qué datos consulta, cómo se procesan y cómo revocar el acceso.
- `terms.html` — condiciones breves de uso personal.
- `style.css` — hoja de estilo compartida.

El sitio es estático: sin backend, sin formularios, sin analítica propia,
sin cookies ni anuncios. No contiene datos de calendario ni credenciales.
El alojamiento es GitHub Pages: según la documentación oficial de GitHub,
la dirección IP de las visitas se registra y conserva con fines de
seguridad, haya sesión iniciada o no.
